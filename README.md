# Stagehand

Local orchestrator that walks a ClickUp ticket through fixed stages using headless Claude Code (`claude -p`), pauses where a human must look, and shows the evidence at each pause.

Design: https://claude.ai/code/artifact/86056b4b-2ffd-4929-8421-1c7063e4f86b

```
npm install
npm run dev        # server :4747, web :5173
```
